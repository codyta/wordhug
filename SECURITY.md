# Security policy

## Supported versions

Only the latest published version of `wordhug` receives fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub instead:
[Report a vulnerability](https://github.com/codyta/wordhug/security/advisories/new).

You'll get a reply within a week. Once a fix is released, the advisory is published with credit to you, unless you'd rather stay anonymous.
