---
title: HTML string
description: wordhugHtml renders text to an escaped HTML string, for any framework or none.
---

`wordhugHtml` turns text into an HTML string, for server templates, `innerHTML`, emails or any framework without its own wordhug component.

```ts
import { wordhugHtml } from "wordhug";

wordhugHtml("Fish & [chips]", { class: "nowrap" });
// → 'Fish &amp; <span class="nowrap" style="display: inline-block">chips</span>'
```

Text and attributes are HTML-escaped, so the result is safe to insert with `innerHTML`, even with text from users.

## Options

| Option | Type | Default | Description |
| --- | --- | --- | --- |
| `as` | tag name | `"span"` | Element that wraps each group. A name that isn't a plain tag name throws. |
| `class` | `string` | – | Class on each group wrapper. |
| `style` | `string \| null` | `"display: inline-block"` | Style attribute on each group wrapper. `null` removes it. |

Empty input (`""`, `null` or `undefined`) returns `""`.

## HTML you already have: `wordhugMarkup`

`wordhugMarkup` does the same for input that is already HTML, such as HTML from a CMS. It's what the [Astro component](/wordhug/frameworks/astro/) uses for its children.

```ts
import { wordhugMarkup } from "wordhug";

wordhugMarkup("<p>Buy [only <strong>$9</strong> today]</p>");
// → '<p>Buy <span style="display: inline-block">only <strong>$9</strong> today</span></p>'
```

- Brackets are read in the text only. Tags, attributes, comments and entities are kept as they are, so `&#91;` is another way to write a literal bracket.
- A group can contain inline elements, but can't start in one element and end in another. Text in elements without groups is left unchanged.
- `<code>`, `<pre>`, `<kbd>`, `<samp>`, `<script>`, `<style>`, `<textarea>`, `<title>`, `<svg>`, `<math>`, `<template>` and `<astro-island>` are left alone.
- The options are the same as `wordhugHtml`.

:::caution
`wordhugMarkup` doesn't escape or sanitize its input, so only pass HTML you trust. For plain text, use `wordhugHtml`, which escapes.
:::
