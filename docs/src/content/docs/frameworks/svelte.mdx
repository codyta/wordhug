Requires Svelte 5. The component ships as source and is compiled by your build, like your own components.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `text` | `string` | – | Text to render. Empty input renders nothing. |
| `as` | tag name | `"span"` | Element that wraps each group. |
| `class` | `string` | – | Class on each group wrapper. |
| `style` | `string \| null` | `"display: inline-block"` | Style attribute on each group wrapper. `null` removes it. |

The text goes in the `text` prop rather than the children, because a Svelte 5 snippet can't be read as text.

## `wordhug()`

Returns the same output as an HTML string, with the text escaped, for `{@html}`. Options are `as`, `class` and `style`, as for the component:

```svelte
<script>
  import { wordhug } from "wordhug/svelte";
</script>

<h1>{@html wordhug("Fresh bread [delivered daily]", { class: "nowrap" })}</h1>
```
